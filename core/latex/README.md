# LaTeX Module

This module provides the LaTeX compilation functionality for the resume builder application. It handles the generation of LaTeX documents from templates and data, and the compilation of those documents to PDF.

## Components

- `base.py`: Base classes for LaTeX compilation
- `compilers/`: Specific compilers for different document types
  - `resume.py`: Compiler for resume documents
  - `cover_letter.py`: Compiler for cover letter documents
- `processors/`: Section-specific content processors
  - `base.py`: Base processor class defining the interface
  - `personal_info.py`: Processor for personal information
  - `skills.py`: Processor for skills section
  - `work_experience.py`: Processor for work experience section
  - And others for each resume section
- `utils/`: Utility functions for LaTeX processing
  - `placeholder.py`: Template placeholder management
  - `safety.py`: LaTeX safety functions (escaping and sanitization)

## Architecture

The LaTeX module uses a clean separation of concerns:

1. **Base Compiler (`base.py`)**:
   - Provides abstract base class `LatexCompiler` for LaTeX compilation
   - Handles the compilation process, file management, and cleanup

2. **Specialized Compilers**:
   - `ResumeCompiler`: Generates and compiles resume documents
   - `CoverLetterCompiler`: Generates and compiles cover letter documents

3. **Section Processors**:
   - Each resume section has a dedicated processor
   - Processors handle content parsing, validation and LaTeX formatting
   - All inherit from `SectionProcessor` base class
   - Accessible via `get_processor_for_section(section_name)`

4. **Utility Functions**:
   - `placeholder.py`: Manages placeholders in LaTeX templates
   - `safety.py`: Provides character escaping and content sanitization

## Processing Flow

The processing flow is:

1. **Content Generation**: Resume content is generated by the `ResumeGenerationService`
2. **LaTeX Document Generation**: The `LatexService` generates LaTeX documents using appropriate compilers
3. **Section Processing**: Each section is handled by its dedicated `SectionProcessor`
4. **PDF Compilation**: The LaTeX is compiled to PDF using the compiler

## Usage

The LaTeX module should be used through the unified `LatexService` in `core/services/latex_service.py`.

### Example Usage

```python
from core.services.latex_service import get_latex_service

# Get the LaTeX service with all repositories initialized
latex_service = get_latex_service()

# Generate LaTeX for a resume
resume_latex = await latex_service.generate_resume_latex(resume, profile)

# Compile LaTeX to PDF
pdf_bytes = await latex_service.compile_latex_to_pdf(resume_latex, is_cover_letter=False)
```

### Using Section Processors Directly

```python
from core.latex.processors import get_processor_for_section

# Get processor for a specific section
skills_processor = get_processor_for_section("skills")()

# Process skills data into LaTeX
skills_latex = skills_processor.process(skills_data)
```

### Using LaTeX Safety Utilities

```python
from core.latex.utils import sanitize_latex, escape_latex

# Sanitize user input for safe LaTeX output
safe_text = sanitize_latex(user_input)

# Format a sanitized paragraph with proper line breaks
paragraph = sanitize_latex_paragraph(user_input)
```

## Templates

Resume and cover letter preambles live under `templates/latex/` and are loaded by
`core/latex/template_registry.py` (classic, modern, academic, etc.). Section markup
is produced by `core/latex/processors/`.

```python
from core.latex.template_registry import get_resume_template, list_resume_templates

templates = list_resume_templates()
preamble = get_resume_template("modern")["preamble"]
```

## Extending

The modular design makes it easy to extend the system:

1. **Adding a New Section Processor**:
   - Create a new class in `processors/` that inherits from `SectionProcessor`
   - Implement the `process` method
   - Add the processor to the `SECTION_PROCESSORS` map in `processors/__init__.py`

2. **Adding a New Document Type**:
   - Create a new compiler class in `compilers/` inheriting from `LatexCompiler`
   - Implement the `generate_tex_content` method
   - Add appropriate methods to `LatexService` for the new document type

## Notes

- The separation of content processing from document compilation improves maintainability and testability
- All section-specific processing logic is contained in the respective processor classes
- LaTeX safety utilities ensure secure and properly formatted output
